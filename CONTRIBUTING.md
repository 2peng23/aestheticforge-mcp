# Contributing

Use Node20.20+ and `npm ci`. Run build, unit tests, stdio smoke and the real browser demonstration before proposing behavior changes. Keep stdout reserved for MCP. Pin compatible dependencies and inspect audit output.

Add capabilities as real measurable operations or explicit client-authored specifications. Do not add tool names that return generic advice or aesthetic scores. Keep transport separate from services, label heuristic findings, preserve host application behavior and document optional integrations.

Security changes need traversal, private-file, symlink, malformed-input and write-precondition regression tests. Browser changes should preserve origin filtering, privacy masks, resource limits and teardown. Tests must use isolated local sample data. Never commit actual credentials, personal captures, node_modules or generated artifacts. Submit a reviewable patch; no remote publication is performed by the development scripts.
